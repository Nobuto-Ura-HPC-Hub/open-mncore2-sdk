# 49-reduce-pe-vec — PE 全段縮約 v 付き (4 レジスタ同時縮約)

48-reduce-pe の拡張版。v サフィックスにより 4 つのレジスタを同時に縮約する。

## v なし (48-reduce-pe) との違い

| | v なし | v あり (本 example) |
|---|---|---|
| l1bmp | $lr0 に 1 値を放送 | $lr0, $lr2, $lr4, $lr6 に 4 値を配布 |
| l1bmrdfadd | 4 サイクルとも $lr0 を読む | cycle ごとに $lr0, $lr2, $lr4, $lr6 を読む |
| PDM 出力 | 4 u64 (意味のある値) | **16 u64** (4 cycle × 4 PE position) |

## 入力と結果

入力: [1.0, 2.0, 3.0, 4.0] の繰り返し → PE の $lr0=1.0, $lr2=2.0, $lr4=3.0, $lr6=4.0

PDM に 16 u64:

| cycle | src レジスタ | PDM 値 (× 4 PE position) |
|-------|------------|-------------------------|
| 0 | $lr0 = 1.0 | 1024.0 |
| 1 | $lr2 = 2.0 | 2048.0 |
| 2 | $lr4 = 3.0 | 3072.0 |
| 3 | $lr6 = 4.0 | 4096.0 |

Total: (1024 + 2048 + 3072 + 4096) × 4 = 40960.0 = 4096 PEs × (1+2+3+4)

## 用途

複数の変数を同時に縮約したい場合（例: 平均と分散を 1 回の縮約で計算）。
