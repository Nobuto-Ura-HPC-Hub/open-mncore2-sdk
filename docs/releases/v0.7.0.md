# v0.7.0

## トピック

### いろんなアプリに対応しました

- N Body
  - 8台の MN-Core 2 を使い 262144 粒子で、球状星団の衝突シミュレーションができるようになりました。
- バイトニックソート
- FFT
- ２次元の熱拡散
- 姫野ベンチ

### 機能追加

- sin/cos への対応
- OpenCL C の標準関数（数学関数）の一部への対応
  - 対応している関数はまだ限られています。sqrt、exp、log など、多くの関数は今後の対応となります。
- 複数 MN-Core 2 の協調動作の確認
- MN-Core 2 内のDRAM の有効利用
