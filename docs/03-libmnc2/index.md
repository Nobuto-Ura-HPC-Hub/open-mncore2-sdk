# libmnc2 を使った開発

libmnc2 は MN-Core2 プログラミングの中核ライブラリです。このセクションでは、libmnc2 を使用したアプリケーション開発方法を解説します。

## libmnc2 について

libmnc2 は以下の機能を提供します：

- MN-Core2 ハードウェアへのプログラミングインターフェース
- メモリ管理とデータ転送機能
- カーネル実行制御
- デバッグおよびプロファイリング機能

- MN-Core2 SDK がインストール済みであること
- C/C++ の基本的な知識
- MN-Core2 のハードウェア構成についての理解（[MN-Core2 について](../01-mncore2/)を参照）
