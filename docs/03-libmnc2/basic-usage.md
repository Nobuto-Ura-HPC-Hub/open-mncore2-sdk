## ライブラリのリンク

libmnc2 をプログラムにリンクするには、コンパイル時に libmnc2 ライブラリを指定します。

```bash
# コンパイル例
gcc -o my_app my_app.c -L${MN_CORE2_SDK}/lib -lmnc2 -I${MN_CORE2_SDK}/include
```
